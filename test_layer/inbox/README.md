# 测试层待处理箱（inbox）

本目录用于放置经 H5 上传校验后下载的「测试层待处理包」（JSON）。

约定：

- 只放汇总包。不要放入公司明细，也不要放入命中明细列名（如薪酬明细、运单号、客户名单、车辆轨迹、趟次明细、加盟合同等）的文件或取值。
- 「轨迹断更」是汇总票数，可以作为汇总字段。
- 包内必须带来源类型，且只允许：假设 / 公开来源 / 合规授权汇总 / Danny提供的汇总。
- 包的状态是「待测上传」，并标明「非正式，尚未演算」。不会自动演算，更不会写入 `formal_layer/`。
- 本目录不对接极兔内部系统，不保存被拒绝的内容。

H5 第一版没有后端，不会自动写入本目录。请将浏览器下载的 JSON（如需原图或 PDF，一并）手工放到这里，供后续测试层内核处理。

不要在本目录留下明细样例。
