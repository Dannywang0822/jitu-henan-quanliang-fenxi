## 打开方式

GitHub Pages 已关闭，在线链接已撤掉。请在本目录启动本地服务，以便读取 `data/`：

```bash
cd h5
python3 -m http.server 8765
```

然后用浏览器打开 <http://127.0.0.1:8765/>。

也可以直接打开 `h5/index.html`，但部分浏览器会限制 `file://` 读取 JSON/Markdown。

界面按 375px 手机宽度优先，电脑浏览器也可以用。

## 三个入口

1. **整体结论**：发现、方案、缺数，以及可展开的详细测算。
2. **各部门重点关注目标**：九个部门状态，点进查看该部门方案、缺数和详细测算。运力归营运部，不单列。
3. **上传录入**：传汇总（JSON / 表格 / 图片 / PDF）或手机拍照。必须先选来源类型。通过校验后下载「测试层待处理包」，可手工放到 `test_layer/inbox/`。照片和 PDF 第一版不做识别，不会把影像当成已演算数字。

明细列名会被整份拒绝且不留存。不要把待处理包写入 `formal_layer/`。

仓库根目录 README 已补充本页打开方式。
